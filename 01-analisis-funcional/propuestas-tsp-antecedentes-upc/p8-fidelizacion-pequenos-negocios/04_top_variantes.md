## 1. V4 — Lealtad B2B: distribuidora → bodegas (66)

| Campo | Contenido |
|---|---|
| Cliente | Distribuidoras medianas del canal tradicional (500–5 000 bodegas) |
| Comprador / usuario | Gerente comercial / bodeguero (consulta sus puntos por WhatsApp o enlace) |
| Problema | Bodegas que reducen su compra o se van a otro proveedor [H] |
| Solución | Importa el historial de pedidos por bodega → segmentación (RFM) y alerta de caída → puntos por compra y metas de recompra → canje de premios → campañas a segmentos con **grupo de control** → reporte de efecto |
| Diferenciador | Diseñado para el proveedor, no para el comercio; medición causal del efecto |
| Métrica | Tasa de recompra por bodega; bodegas recuperadas; incremento de compra frente al grupo de control |
| Precio tentativo [H] | Por bodega activa al mes (S/ 0,50–1,50) con mínimo |
| Riesgo | Costo de los premios; grandes marcas con programas propios [PI]; integración con el sistema de pedidos |
| Sinergia | Mismo cliente que P1-V6 (pedido sugerido), P5-V1 (preventa) y O2 (captura de pedidos) |
