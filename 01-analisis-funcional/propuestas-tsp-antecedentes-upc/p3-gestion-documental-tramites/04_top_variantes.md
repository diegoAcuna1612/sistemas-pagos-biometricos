**Fecha:** 05/11/2026. Etiquetas y fuentes en `10_fuentes_y_evidencias.md`. Puntajes en `09`.

## 1. V4 — Expedientes de clientes con validación IA (64)

| Campo | Contenido |
|---|---|
| Cliente | Inmobiliarias (crédito hipotecario, Mivivienda), financieras y cooperativas pequeñas, corredores de seguros |
| Comprador / usuario | Gerente comercial u operaciones / asesor y analista |
| Problema | Expedientes que llegan incompletos o con errores; idas y vueltas con el cliente [H] |
| Solución | Enlace o WhatsApp para que el cliente suba documentos → clasificación y extracción → **lista de verificación automática** (falta, vencido, no coincide, ilegible) → aviso inmediato al cliente → expediente con código de seguimiento → bandeja del analista |
| Diferenciador | Reglas de requisitos configurables por producto; validación del contenido, no solo del flujo |
| Métrica | % de expedientes completos al primer envío; días hasta expediente completo; minutos de revisión por expediente |
| Precio tentativo [H] | Por expediente con mínimo mensual (`07`) |
| Riesgo | Datos personales sensibles (ingresos); integración con el CRM; IDP genéricos |
